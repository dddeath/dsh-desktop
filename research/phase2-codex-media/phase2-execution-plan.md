# 阶段 2：Codex 额度视觉识别与图片生成插件执行计划

状态：等待用户验收执行顺序；验收后从操作 1 开始。

## 原则

- 优先复用本机 Codex/ChatGPT OAuth 登录态与订阅额度，不引入独立 API Key 计费路径。
- 一次只试装一个候选，避免重复注册模型或同名工具。
- 自动验证只保留启动、注册、HTTP 与恢复能力四项硬门禁。
- 功能正确性、UI 可见性、读图质量和生成图片质量优先由用户人工判断。
- 每个人工验收点通过后再进入下一步，并在 Git 中形成独立检查点。

## 操作 1：候选源码核验，不安装

候选顺序：

1. `dsh-codex-tools`：目标最直接，声明提供 `image_vision`、`image_gen` 并复用 ChatGPT OAuth。
2. `dsh-plugin-codex`：作为 Codex App Server 模型与工具桥接备选。
3. `dsh-codex-connect`：作为 OAuth 模型接入与可选图片工具备选。

检查字段：实际授权实现、是否读取本机 Codex 登录态、是否要求 API Key、工具名称、产物保存方式、Windows 路径兼容、安装和卸载命令、依赖与维护状态。

交付：三候选对比表、推荐项、排除理由、拟执行安装命令。

### 人工验收 A

用户确认推荐插件和安装命令后进入操作 2。

## 操作 2：备份并单插件试装

1. 导出当前 web profile 的插件清单、`package.json`、锁文件和 Cordis 配置哈希。
2. 保存配置副本与恢复脚本。
3. 只安装人工确认的一个候选。
4. 重启 DSH，确认 HTTP 200、插件已加载且阶段 1 UI 正常。

自动门禁：命令退出 0、HTTP 200、插件出现在清单、页面无启动错误。

### 人工验收 B

用户在设置页确认：插件名称、版本、启用状态，以及对话区能看到视觉识别和图片生成入口。

## 操作 3：OAuth 登录路径

1. 打开插件提供的 Codex/ChatGPT 登录入口。
2. 用户本人核对授权页面、账号与套餐信息并完成确认。
3. 记录成功状态，不记录令牌内容。

自动门禁：插件报告已登录，且配置中没有新增 API Key 要求。

### 人工验收 C

用户确认登录状态来自目标 ChatGPT/Codex 账号，并同意开始消耗一次读图测试额度。

## 操作 4：视觉识别测试

1. 用户指定或提供一张测试图片。
2. 从 DSH 对话入口调用视觉工具。
3. 展示工具轨迹、输入图片与识别结果。

自动门禁：工具调用完成、返回结构可解析、无路径错误。

### 人工验收 D

用户按图片内容判断主体、文字、布局和细节是否准确；通过后进入生图测试。

## 操作 5：图片生成测试

1. 用户给出提示词。
2. 从 DSH 对话入口调用图片生成工具。
3. 将生成图片保存为可打开的本地文件，并在对话中展示。

自动门禁：工具调用完成、文件存在、图片可解码。

### 人工验收 E

用户判断提示词遵循度、画面质量和 DSH 内展示效果。

## 操作 6：持久化与恢复验收

1. 重启桌面端，确认插件、登录状态和工具入口仍可用。
2. 展示卸载与恢复命令。
3. 由用户决定执行真实卸载/恢复，或仅保留恢复资产。
4. 记录最终版本、配置哈希和 Git 提交。

### 人工验收 F

用户确认保留当前方案或执行恢复；验收后阶段 2 完成。

## 停止条件

- 候选实际要求独立 API Key 或第三方转发网关。
- 只接入 Codex 文本模型，不提供可用的视觉识别与图片生成工具。
- 与现有 ModLens 或模型路由产生同名注册冲突。
- Windows 下产物路径不可用，且修复成本超过新建本地桥接插件。

触发停止条件时，回到安装前 profile，并提交证据与下一候选建议。
